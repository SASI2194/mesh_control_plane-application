🧠 2. Neighbour Selection Governance & Network Inclusivity Algorithm

To prevent UGV-05 (or any single-peer edge node) from being left out (isolated) from the mesh network, the governance algorithm applies two strict operational rules:

  • Max Neighbor Capacity Rule: Every node selects a maximum of 2 Active Neighbours (Rank 1 = ⭐ PRIMARY ACTIVE, Rank 2 = 🛡️ STANDBY BACKUP / SECONDARY ACTIVE). Bandwidth is dynamically shared (50%/50%) between active links.
  • Network Inclusivity (Isolation Prevention) Rule: If UGV-05 has only 1 peer connection (UGV-01), purely selecting top quality links (UGV-03 & UGV-04) would disconnect UGV-05. Therefore, UGV-01 reserves its Rank 2 Active Neighbour slot for UGV-05 to guarantee 100% network connectivity, while UGV-04 maintains its active mesh link through UGV-03.
